# World Border Event — Forge 1.20.1 (Forge 47.x, Java 17)

Собственная энергетическая граница с кинематическим ивентом. Ванильная граница не используется (она общая для измерений).

## Команды (OP, уровень 2) — не менялись
- `/wbe set <radius>` — радиус квадрата от центра (0,0). Незер = Верхний мир / 8.
- `/wbe event start` — запуск ивента. `restart` — перезапуск от текущего радиуса. `stop` — остановка со сбросом радиуса. `status` — состояние.
- `/wbe brightness [0.2–3.0]` — яркость барьера (по умолчанию 1.4; без аргумента показывает текущую). Хранится в мире и действует у всех игроков.

## Сценарий ивента (20 тиков = 1 с)
| Время | Что происходит |
|---|---|
| 0–3 с | гул глохнет, появляется низкий рокот, лёгкая тряска, свечение растёт; граница неподвижна |
| 3–8 с | нарастание звука, вспышки и малые ударные волны по стене, тряска усиливается |
| 8–12 с | кульминация: волна по стене, глубокий удар, максимум свечения; граница по-прежнему неподвижна |
| 12–30 с | плавное отдаление на 1000 блоков (Незер — 125); после ~800 блоков стена начинает таять и к 1000 исчезает |
| 30–35 с | затухание звуков; стена исчезла и физически снята |

В конце отдаления барьер исчезает полностью: визуально и физически (ограничение снимается). `/wbe set <radius>` ставит его снова. Сверху стена за 50 блоков плавно растворяется в небе. Раз в минуту барьер издаёт по очереди два звука (файлы `pulse_a.ogg`, `pulse_b.ogg`), слышные только вблизи стены (до ~160 блоков). Во время пробуждения звучат удары по бочке с нарастающей громкостью.

## Реакция на удары
- Удар рукой — малая волна; меч/инструмент — сильнее (клиент -> сервер -> все игроки измерения).
- Снаряды (стрелы, пули TACZ и т. п. — всё, что наследует `Projectile`) останавливаются границей, в точке попадания рябь и искра.
- Лимиты: слияние близких эффектов, не более 24 активных эффектов, не более 8 рассылок за проход сервера, задержек между ударами нет.

## Настройки клиента (`config/worldborderevent-client.toml`)
`shakeIntensity` (0–1), `particles`, `reduceFlashes`, `soundVolume`.

## Сохранение и синхронизация
Состояние (радиус, идущий ивент, тик) хранится в данных мира; после перезапуска ивент продолжается с того же тика. Сервер — источник истины, клиент только рисует. Вошедший позже игрок и сменивший измерение получают актуальное состояние.

## Ресурсы
Текстуры и звуки сгенерированы `tools/gen_assets.py` (numpy, Pillow, ffmpeg); готовые файлы лежат в `src/main/resources/assets/worldborderevent`. Можно заменить своими с теми же именами.

## Статус проверки
Код написан без локальной сборки и без запуска игры. Проверяется сборкой GitHub Actions и в игре. Совместимость с Embeddium/Oculus не проверена.

## Отладка (клиентская команда, без прав OP)
- `/wbedebug` — снимок состояния (радиус, расстояния до стен, куда смотрит игрок, что нарисовано в последнем кадре) в чат и в `latest.log`.
- `/wbedebug hide true|false` — выключить/включить отрисовку стены (проверить, она ли даёт артефакт на экране).
- `/wbedebug trace true|false` и `/wbedebug log true|false` — писать состояние рендера/мира в `latest.log`.
